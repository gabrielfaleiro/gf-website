## Tips for Better Results

1. **Iterate** - If first approach doesn't match, try different keywords
2. **Use stack flag** - Get implementation-specific best practices
3. **Always check UX** - Search "animation", "z-index", "accessibility" for common issues
4. **Combine domains** - Style + Typography + Color = Complete design system
5. **Be specific** - "healthcare SaaS dashboard" beats "app"

## Output Formats

When documenting design systems:

- **ASCII box** - Best for terminal display
- **Markdown** - Best for documentation and Cursor context
